## ⚡ Featured Projects & Case Studies

### 1. FogVision: Hybrid Quantum-Classical Image Dehazing
- **Architecture**: EfficientNet-B0 fog density classifier coupled with a hybrid quantum-classical U-Net bottleneck.
- **Quantum Circuit**: 4-qubit parameterized Variational Quantum Circuit (VQC) with cyclic CNOT entanglement gates in Hilbert latent space.
- **Edge Deployment**: Exported to ONNX Runtime graphs achieving sub-30ms edge inference without external quantum cloud dependencies.
- **Dataset**: Validated on Cityscapes-DBF across multiple fog attenuation conditions ($\beta = 0.010, 0.005$).
- **Repository**: [https://github.com/tamilselvan526/QuantumDehazer](https://github.com/tamilselvan526/QuantumDehazer)

### 2. Automated Casting Defect Classification
- **Domain**: High-throughput Automated Optical Inspection (AOI) for metal die-cast pump impellers.
- **Architectures**: Comparative benchmark across Custom SE-CNN (Squeeze-and-Excitation attention with SiLU activations), MobileNetV2, and ResNet50.
- **Classification**: 4 distinct classes (`Blowhole`, `Crack / Tear`, `Parting Line Flash`, and `Normal Non-Defective`) with real-time factory disposition routing actions.
- **Serving**: Flask REST inference microservice.
- **Repository**: [https://github.com/tamilselvan526/Automated-casting-defect-classification-using-multiple-cnn](https://github.com/tamilselvan526/Automated-casting-defect-classification-using-multiple-cnn)

### 3. ShopKart Full-Stack Commerce System
- **Stack**: React 18/19, Redux Toolkit, RESTful endpoints, and relational MySQL persistence.
- **Features**: Real-time faceted catalog filtering, optimistic cart state transactions, and signed JWT role-based access control (RBAC).
- **Repository**: [https://github.com/tamilselvan526/shopkart](https://github.com/tamilselvan526/shopkart)

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/tamilselvan526/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
